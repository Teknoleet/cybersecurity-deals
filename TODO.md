# Cybersecurity Deals — Stage 1 outcomes

- [x] **Approved visual directory.** Public account-free directory at intended domain deals.teknoleet.com; graphite/lime design matching approved v2 concept. Site name only; no secondary branding, header tabs, category tabs, or collection-frequency slogans. Heading “Less spend. More security.”, subtitle “Cybersecurity offers. Sources included.”, status card “Last Check”. Two columns desktop, single column mobile, accessible collapsible category/vendor/topic filters, readable source conditions and stale warnings, keyboard focus and reduced-motion support.
- [x] **Functional discovery controls.** Keyword search covers vendor/product/description/tags/coupon, case-insensitive; vendor and topic filters plus product-type category dropdown. Groups AND; selected topics OR. Shareable query parameters, counts, reset, no-results state, newest discoveries first, stale offers after confirmed offers. Copy coupon feedback and expandable evidence/terms; no checkout testing.
- [x] **Public content is genuine.** No fictional mockup offers. Initial offers supported by accessible live official evidence. Historic, conflicting, unsupported, unknown-date and expired offers excluded from current results; unknown fields remain null. Future offers labeled upcoming, not currently redeemable. 2026 campaign evidence or original October 2026 article publication required; footer years/updated 2025 pages do not qualify. General and Black Friday promotions labeled separately.
- [x] **Categories and seller policy.** Training & Labs, Certifications & Exams, Software & Tools, Hardware, Books & Bundles. Security topics include offensive, blue/DFIR, AppSec, cloud/DevSecOps, AI, OSINT, reverse engineering, physical security, privacy/VPN. Distinct LLM/agent/MCP/adversarial-ML/AI-for-security tags where supported. No generic AI products. Marketplace book/training bundles labeled third-party; software licenses excluded unless authorization established.
- [x] **Python collection and deduplication.** Deduplicated Git-managed source registry drawn from attachment with explicit source capability/health. Supported parsers for accessible sources, bounded relevant link discovery, unsupported candidates retained for Git changes rather than silently published. Merge repeated same product/plan/billing/coupon/region with all provenance; distinct plans remain distinct. When the same offer appears twice, the most recently confirmed price is published. No paid APIs or LLM extraction.
- [x] **Honest failure and date handling.** Track last attempt, successful fetch and offer confirmation independently. Last Check is latest completed collection, not proof every source succeeded. Conditional requests cannot freshen unmatched representations. Retain last-known-good on failures; derive stale after three hours client-side even if collection stops. Explicit withdrawal/expiry removes current offers; fetch failure alone does not expire. No guessed expiry/timezones.
- [x] **Current prices only.** Owner decision, 8 November 2026: no price history and no price cross-checks. The only eligibility criterion for a price is that it belongs to a 2026 offer; the vendor's current price, and its crossed-out price when it shows one, are displayed as published. No invented renewal terms, prices or savings.
- [x] **Portable free static output.** Python generation of meaningful HTML, JSON, static CSS/JS; no Node.js backend, managed database or paid service. Cloudflare Workers Static Assets configuration, static-only routes /, /sources/, /methodology/ before Preview. Real unknown-route 404, per-route metadata and intended-origin links. Short/revalidated mutable cache and fingerprinted assets, browser checks for newer snapshots without vendor requests.
- [x] **Scheduled automation.** GitHub workflow collects every 30 minutes at minutes 17 and 47 (best-effort) and on manual dispatch, standard public runners only; publication gated by `GO_LIVE_APPROVED` and the `production` environment. Scoped deployment secrets not committed; state/data branch persistence, no data-commit deployment loops, no artifacts database or paid overages. No public repo creation, Cloudflare publication, DNS change or enabled recurring jobs without later go-live authorization.
- [x] **Security boundaries.** Escaped remote text, no raw HTML injection; URL scheme/private/local/metadata and redirect protections; bounded fetch sizes/timeouts/retries/concurrency; no auth/CAPTCHA bypass; source access policies respected. Pinned actions/dependencies, least-privilege workflow jobs, no secrets for untrusted pull requests. Compact evidence only, bounded state history.
- [x] **Reviewable handoff.** Local Preview runs on configured port; collector/policy and frontend checks pass. Read-only validation agent traces implementation against this TODO and plan; confirmed issues corrected. README documents collection, Git config/overrides, source limitations, free-tier caveats, safe activation and Cloudflare setup. Save a checkpoint without publishing.
